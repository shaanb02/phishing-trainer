Understanding Phishing Attacks

What is phishing?

Phishing is a cybercrime where attackers impersonate legitimate organizations to steal sensitive information like passwords, credit card numbers, or personal data.

Common Types:
  • Email Phishing: Fake emails from trusted sources
  • Smishing: Phishing via SMS text messages
  • Vishing: Voice phishing through phone calls
  • Website Spoofing: Fake websites that look legitimate
Identifying Red Flags

Watch out for these warning signs:

🚩 Major Red Flags
  • Urgent language ("Act now!", "Limited time!")
  • Threats of account closure or legal action
  • Requests for sensitive information via email
  • Generic greetings ("Dear Customer")
  • Suspicious sender email addresses
  • Poor grammar and spelling errors
  • Unexpected attachments or links
  • Offers that seem too good to be true
💡 Pro Tip

When in doubt, contact the organization directly using official contact information, not the details provided in the suspicious email.

Security Best Practices
Before Clicking Any Link:
  1. Hover First: Hover over links to see the actual destination URL
  2. Verify Sender: Check if the sender's email address is legitimate
  3. Check Context: Was this email expected? Does it make sense?
  4. Use Official Channels: Go directly to the organization's website
  5. Ask for Help: When unsure, contact your IT security team
Additional Security Measures:
  • Enable two-factor authentication (2FA)
  • Keep software and browsers updated
  • Use strong, unique passwords
  • Regular security training
